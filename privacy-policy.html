Chrome Extension

1. Introduction

This Privacy Policy describes how PageEraser ("the Extension", "we", "our") handles user data. PageEraser is a Chrome/Edge browser extension for working with the pages you visit: it lets you erase and stretch elements, look at a page's layout (Layout X-Ray), copy an element's HTML and CSS (Extract to Code), compare a page against a design image (Visual Diff) and paint on a page. We are committed to protecting your privacy and being transparent about our data practices.

🔒

PageEraser does NOT collect, transmit, or share any personal data.

2. Data Collection

PageEraser does not collect any personal information or user data. Specifically:

  • No personal information (name, email, address, etc.) is collected
  • No browsing history or activity is tracked
  • No analytics or telemetry data is gathered
  • No cookies are set by the extension
  • No account or sign-in; nothing identifies you
  • No data is transmitted to any external server: the extension makes no network requests of its own
  • No third-party tracking scripts are used
  • No advertising networks are integrated

3. Local Data Storage

PageEraser stores the following data locally on your device in the browser's extension storage (chrome.storage.local). It exists only because a feature needs it, and you can see, export or delete it at any time (see section 9).

Data Type What it contains Purpose
Erase and stretch rules For each site you use PageEraser on: the site's domain name, and for each element the CSS selector that finds it, whether it is hidden or stretched, and whether you deleted it for good from the Recycle Bin. No page text and no page content. Apply your rules again when the page reloads
Preferences Language, theme, contrast, text size, sound on/off, Clippy on/off, whether the intro tour was completed, whether rules apply to all subdomains or persist, and the X-Ray depth Remember how you set the extension up
Visual Diff settings Per site: the design's position, scale, opacity, display mode and comparison threshold Put the overlay back where you left it
Visual Diff image The design image you loaded for a site, stored as it was loaded when it fits in 5 MB. A larger image (up to 25 MB) is shown for that visit only and not stored. Show your design again on that site; Remove image deletes it
Toolbar badge count The number of hidden elements per open tab, in chrome.storage.session Show the count on the toolbar icon; cleared when the browser closes
Important: All data remains entirely on your device. No data is ever sent to any remote server, cloud service, or third party. The extension works fully offline after installation.

Earlier versions kept the same data in chrome.storage.sync, which Chrome can sync through your Google account when you have browser sync turned on. The current version moves anything it finds there to local storage once, then clears it from sync, so new data is never synced by the extension.

4. What PageEraser Reads From Pages

The extension's content script runs on the pages you visit so that your saved rules can be applied as soon as a page loads and so that its tools are ready when you start them. It reads a page only to do what you asked, and it does not keep or send what it reads:

  • Erase / Stretch: looks at the element you pick to build a selector for it. Only the selector is saved.
  • Layout X-Ray: measures element sizes and positions and draws them over the page. Nothing is saved. Capture takes an image of the visible part of the tab, adds the overlay and saves it as a PNG through the browser's normal download, according to your download settings. The extension does not keep a copy.
  • Extract to Code: reads the HTML and computed styles of the element you pick and shows them in a panel on the page. It is copied to your clipboard only when you press a copy button. Nothing is saved, and font files are listed, never downloaded.
  • Visual Diff: shows the image you load (from a file, a paste or a drag-and-drop) over the page. Compare takes an image of the visible tab, compares its pixels with your design in memory and discards it. The design image is not sent anywhere. While the mode is active the image is drawn on the page you are viewing, so, like anything shown on a page, a script of that page could in principle read it: do not load a confidential design on a page you do not trust.
  • Paintbrush: draws on the page you are viewing. Nothing is saved.

5. Permissions Explanation

The extension requires certain browser permissions to function. Here is a transparent explanation of each permission and why it is needed:

Permission Why It's Needed
storage To save your rules, preferences and Visual Diff settings and image locally on your device
activeTab To work with the current tab when you start a tool from the toolbar button, a keyboard shortcut or the right-click menu, including taking an image of the visible tab when you press Capture (X-Ray) or Compare (Visual Diff). It gives access to the tab only after you invoke the extension on it.
contextMenus To add "Erase Element" and "Stretch Element" options to the right-click menu
<all_urls> To run the content script on any webpage so your saved rules apply on every site you have used PageEraser on, as soon as the page loads

PageEraser does not request the tabs, history, cookies, downloads, clipboardRead, webRequest or identity permissions, and it never reads your browsing history.

6. Third-Party Services

PageEraser does not use any third-party services, APIs, analytics platforms, or advertising networks. The extension is completely self-contained and operates entirely within your browser.

7. Data Sharing

We do not sell, trade, rent, or otherwise share any user data with third parties. Since no data is collected, there is nothing to share.

8. Data Security

All data stored by PageEraser stays in your browser profile on your device. The browser's extension model keeps it:

  • Accessible only to the PageEraser extension: web pages and other extensions cannot read it
  • Removed automatically when the extension is uninstalled

The extension does not encrypt this data itself. Anyone who can open your computer account or browser profile can read it, as with any other data in your profile.

9. User Rights & Data Deletion

You have full control over your data at all times:

  • View your data: Open the PageEraser popup to see all stored rules for the current site
  • Delete specific rules: Use the "Restore" button next to any rule, or drag it to the Recycle Bin
  • Delete all rules for a site: Click "Restore All Layout" in the popup
  • Export and import your rules: Use File → Export Rules to save all rules as a JSON file, and File → Import Rules to load one. The file goes where you save it; nothing is uploaded
  • Delete a Visual Diff image: Use Remove image in the Visual Diff toolbar
  • Delete all data: Uninstalling the extension automatically removes all stored data

10. Children's Privacy

PageEraser does not knowingly collect any information from children under 13 years of age. The extension does not collect any personal information from any user regardless of age.
