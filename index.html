PageEraser.exe

Erase any element from any page.

PageEraser is a free Chrome extension. Click what you don't want to see (a cookie bar, a sticky header, a sidebar, a pop-up) and it stays hidden every time you come back. It can also X-ray a page's layout, copy a component as HTML and CSS, and lay a design over the live page to show where they differ.

Features

Erase.exe

Erase it once. It stays erased.

Hover to highlight, click to hide. The arrow keys climb the page's tree so you can pick exactly the container you mean, and Alt+click stretches an element to full width instead.

  • Rules are saved per site and applied again on every load
  • Undo right after an erase, or restore any rule from the Recycle Bin
  • Export your rules, or share a site's rules as one line of text

Start with Alt+Shift+E or the toolbar button.

Layout X-Ray.exe

See how a page is built.

One click draws the layout over the page: flex, grid, block and inline-block boxes in different colours, margin and padding shaded, gaps as dashed lines. Hover an element for its tag, size and display.

  • A depth slider keeps big pages readable
  • Capture saves the visible tab, overlay included, as a PNG

Toggle with Alt+Shift+X.

Extract to Code.exe

Take a component with you.

Pick an element the way the eraser does, but copy it instead of hiding it. You get clean HTML, only the CSS that differs from the browser's defaults, and the fonts and colours it uses as ready-to-paste tokens.

  • Scripts, iframes, inline handlers and data attributes are stripped
  • Font files are listed, never downloaded
  • Copy each tab, or the whole thing as a single HTML file

Toolbar button, or Alt+Shift+C while the page has focus.

Visual Diff.exe

Check a page against its design.

Drop a Figma export or a screenshot onto the page, line it up with opacity, scale and offset, then drag the before/after divider. Compare paints every pixel that differs as a red heat map and tells you the percentage and the number of regions.

  • Works with PNG, JPG and WebP
  • The image and its alignment are remembered per site, on your device only

Toolbar button, or Alt+Shift+V while the page has focus.

Share.exe

Send your cleanup as one line of text.

Copy a site's rules as a code and paste it into a message. Whoever gets it adds it under File → Import from Code, sees exactly what it holds before accepting, and can remove all imported rules with one click. Imported rules can only hide or stretch elements.

About.exe

Yes, it looks like Windows 95. On purpose.

Beveled windows, a Paintbrush overlay for drawing on any page, Clippy with tips (in English and Turkish), synthesized sound effects, and a hidden Minesweeper. Everything can be switched off, and there are high-contrast and large-text modes.

Privacy.exe

Everything stays on your device.

No account, no analytics, no ads, no third-party services. The extension makes no network requests of its own, and your rules live in the browser's extension storage on your computer. You can export or delete them at any time, and uninstalling removes them.

PermissionWhy
storageSaves your rules, settings and Visual Diff image locally.
activeTabLets a tool work on the current tab after you start it, including the screenshot behind Capture and Compare.
contextMenusAdds "Erase Element" and "Stretch Element" to the right-click menu.

PageEraser's content script runs on the pages you visit so your saved rules apply as soon as a page loads. It reads a page only to do what you asked and keeps or sends none of it. It does not use the tabs, history, cookies or webRequest permissions. Read the full privacy policy.

Getting Started.exe

Try it in a minute.

  1. Add PageEraser from the Chrome Web Store and pin it to your toolbar.
  2. Open any page and press Alt+Shift+E, or click the toolbar button and choose Select Element to Erase.
  3. Click what you want gone. Reload the page: it stays gone.

FAQ.exe

Questions

Is it really free?

Yes. PageEraser is free and open source under the MIT license. There is no paid tier, account or ad.

Does it work in Edge, Brave or Opera?

It is built for Chrome (Manifest V3, Chrome 102 or newer). Other Chromium-based browsers can usually install extensions from the Chrome Web Store too, but it is only tested on Chromium.

Does erasing delete anything from the website?

No. PageEraser hides the element in your own browser with a style rule. The site itself is untouched and other people see it as usual.

How do I get something back?

Press Undo in the toast right after an erase, use Ctrl+Z on the page, restore a single rule from the popup or the Recycle Bin, or use Restore All Layout to clear a whole site.

Why does it run on every site?

So the rules you saved for a site apply the moment that page loads. On sites where you have no rules it does nothing, and it does not send anything it reads anywhere. It is also why Chrome's install prompt says the extension can read and change data on all websites.

A site breaks after I erase something. What now?

Restore that rule, or pick a smaller element next time (the ↓ key moves the selection down into a child). If you find a page PageEraser handles badly, please open an issue.
